# Changelog

All notable changes to this project are documented in this file.

## [2.0.0] - 2026-09-15

### Added
- Complete bilingual Persian and English documentation editions.
- Parallel 14-chapter structure under `docs/fa/` and `docs/en/`.
- Dedicated Persian and English MkDocs configurations.
- Root language-selection landing page for GitHub Pages.
- Dedicated `README.fa.md` and `README.en.md` entry points.
- High-quality WebP project banner in both documentation editions.
- Creative Commons Attribution 4.0 International license.
- Automated bilingual structure and local-link integrity checks in CI.
- Unit tests for the documentation integrity checker.

### Changed
- Reorganized the previous single-language documentation into a clean bilingual layout.
- Updated GitHub Actions to strict-build both language editions before deployment.
- Updated contribution guidance for bilingual maintenance.

### Removed
- Legacy single-language documentation layout and obsolete branding assets.
- Internal diagnostic and temporary project files that were not part of the public documentation.

## [1.1.0] - 2026-09-14

### Added
- Professional project branding and optimized README banner.
- CC BY 4.0 licensing information.
- Repository cleanup and simplified public structure.

### Changed
- Improved Persian documentation presentation and project navigation.

## [1.0.0] - 2026-09-12

### Added
- Initial Persian Nmap reference with 14 chapters.
- Learning path, cheat sheet, references, disclaimer, and MkDocs documentation site.
