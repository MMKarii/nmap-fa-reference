# واژه‌نامه دوزبانه Nmap

این صفحه برای جست‌وجوی بهتر و یکدست‌ماندن اصطلاحات فارسی و انگلیسی استفاده می‌شود. نام انگلیسی ابزارها و گزینه‌های Nmap حفظ شده است تا جست‌وجو با هر دو زبان نتیجه بدهد.

| اصطلاح انگلیسی | معادل/عبارت فارسی | کلیدواژه‌های جست‌وجو |
|---|---|---|
| Host Discovery | کشف میزبان | host discovery، کشف host، تشخیص میزبان |
| Port Specification | تعیین پورت | port selection، انتخاب پورت، محدوده پورت |
| Port Scan | اسکن پورت | port scanning، بررسی پورت |
| Scan Type | نوع اسکن | SYN scan، TCP connect، UDP scan |
| Service Detection | تشخیص سرویس | service discovery، شناسایی سرویس |
| Version Detection | تشخیص نسخه | service version، تشخیص ورژن |
| Service & Version Detection | تشخیص سرویس و نسخه | `-sV`، version scan |
| OS Detection | تشخیص سیستم‌عامل | operating system detection، OS fingerprinting، `-O` |
| NSE | موتور اسکریپت‌نویسی Nmap | Nmap Scripting Engine، NSE scripts |
| Timing | زمان‌بندی و سرعت | timing template، performance، `-T0` تا `-T5` |
| Output | خروجی و گزارش | reporting، normal/XML/grepable output |
| Target Specification | تعیین هدف | target، host، subnet، CIDR |
| Firewall / IDS / IPS Evasion | کاهش شناسایی و عبور از کنترل‌های دفاعی در ارزیابی مجاز | firewall، IDS، IPS، evasion |
| TCP SYN Scan | اسکن SYN | half-open scan، `-sS` |
| TCP Connect Scan | اسکن اتصال TCP | connect scan، `-sT` |
| UDP Scan | اسکن UDP | `-sU` |
| Ping Scan | اسکن کشف بدون پورت | ping sweep، `-sn` |
| Top Ports | پورت‌های پرتکرار | `--top-ports` |
| Aggressive Scan | اسکن ترکیبی تهاجمی از نظر حجم اطلاعات | `-A`، OS/version/scripts/traceroute |
| XML Output | خروجی XML | `-oX` |
| Normal Output | خروجی معمولی | `-oN` |
| Grepable Output | خروجی grepable | `-oG` |

## نکته اصطلاح‌شناسی

ترجمه فارسی در این مرجع برای خوانایی است، اما نام گزینه‌ها، switchها، پروتکل‌ها و اصطلاحات رسمی Nmap در صورت نیاز به شکل انگلیسی نیز حفظ می‌شوند. نمونه‌ها فقط برای محیط‌های آموزشی، آزمایشگاهی، مدیریتی و ارزیابی‌های امنیتی دارای مجوز در نظر گرفته شده‌اند.
