# سلب مسئولیت و استفاده مجاز

این مجموعه برای آموزش، مستندسازی و ارزیابی امنیتی مجاز تهیه شده است.

اجرای اسکن روی سامانه، شبکه یا سرویس شخص ثالث بدون مجوز صریح ممکن است با قوانین، سیاست‌های سازمانی یا شرایط استفاده سرویس در تعارض باشد.

پیش از اجرای هر سناریو، محدوده مجاز ارزیابی، زمان اجرا، نرخ اسکن و سامانه‌های هدف را مشخص کنید. در محیط‌های عملیاتی، تغییر نرخ و نوع اسکن ممکن است روی سرویس یا تجهیزات شبکه اثر بگذارد.

مسئولیت اخذ مجوز و رعایت قوانین محل اجرا بر عهده اجراکننده است.
