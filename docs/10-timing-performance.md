# ۱۰. Timing & Performance

کنترل زمان‌بندی برای بهینه‌سازی سرعت، دقت و پنهان‌کاری ضروری است.

## `-T0 (Paranoid) تا -T5 (Insane)`

این یک تنظیم از پیش تعریف شده است که چندین پارامتر زمان‌بندی را به طور همزمان کنترل می‌کند.

- **-T0 (Paranoid):** بسیار کند. ۵ دقیقه فاصله بین ارسال بسته‌ها. برای اسکن بسیار پنهان.

- **-T1 (Sneaky):** کند. ۱۵ ثانیه فاصله. پنهان‌کاری بالا.

- **-T2 (Polite):** معتدل. ۰.۴ ثانیه فاصله. کاهش بار روی شبکه.

- **-T3 (Normal):** حالت پیش‌فرض. تعادل بین سرعت و قابلیت اطمینان.

- **-T4 (Aggressive):** سریع. فرض می‌کند شما روی یک شبکه سریع و قابل اعتماد هستید. ممکن است باعث از دست رفتن برخی اطلاعات شود.

- **-T5 (Insane):** بسیار سریع و تهاجمی. ممکن است باعث از دست رفتن قابل توجه اطلاعات و اشباع شبکه شود.

- **تاثیر روی سرعت:** از T0 به T5 سرعت به شدت افزایش می‌یابد. تاثیر روی دقت: با افزایش سرعت، دقت کاهش می‌یابد (مثلاً timeouts زودتر اتفاق می‌افتند). تاثیر روی شناسایی توسط SOC: سرعت کم (T0,T1) شناسایی را سخت‌تر می‌کند. سرعت بالا (T4,T5) ممکن است به دلیل حجم ترافیک یا الگوهای غیرعادی، توجه را جلب کند.

## `--min-rate و --max-rate`

- **عملکرد:** حداقل و حداکثر تعداد بسته‌ای که Nmap در ثانیه ارسال می‌کند را کنترل می‌کند. --max-rate مفیدتر است.

- **تاثیر:** کنترل دقیق‌تر روی بار شبکه نسبت به سوئیچ -T.

**مثال:**

```bash
sudo nmap -sS --max-rate 100 192.168.1.0/24
```

(حداکثر ۱۰۰ بسته در ثانیه)

## `--min-parallelism و --max-parallelism`

- **عملکرد:** حداقل و حداکثر تعداد پروب‌های موازی (Parallel Probes) را که به طور همزمان در انتظار پاسخ هستند، کنترل می‌کند.

- **تاثیر:** افزایش parallelism سرعت را بالا می‌برد اما ممکن است باعث از دست رفتن پاسخ‌ها در شبکه‌های شلوغ شود.

**مثال:**

```bash
--min-parallelism 50
```

## `--max-retries`

- **عملکرد:** حداکثر تعداد دفعاتی که Nmap پروب‌های timeout شده را مجدداً ارسال می‌کند.

- **تاثیر:** کاهش این مقدار در اسکن‌های سریع (T4/T5) باعث افزایش سرعت می‌شود اما احتمال false negative (پورت‌های filtered که در واقع open هستند) را افزایش می‌دهد.

**مثال:**

```bash
--max-retries 0
```

(بدون ارسال مجدد)

## `--host-timeout`

- **عملکرد:** حداکثر زمانی (به میلی‌ثانیه) که Nmap برای اسکن یک میزبان صرف می‌کند قبل از اینکه آن را رها کرده و به سراغ بعدی برود.

- **تاثیر:** مفید برای جلوگیری از گیر کردن روی میزبان‌های کند یا دارای فایروال پیچیده در اسکن‌های گسترده.

**مثال:**

```bash
--host-timeout 10m
```

(۱۰ دقیقه)
