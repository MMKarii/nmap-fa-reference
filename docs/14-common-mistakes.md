# ۱۴. اشتباهات رایج

## خطاهای رایج کاربران

- **اسکن بدون مجوز:** بزرگترین و پرخطرترین اشتباه.

استفاده از -sS بدون دسترسی Root: منجر به fallback به -sT (Connect Scan) می‌شود که پرسر و صداتر است.

- **ترکیب نادرست سوئیچ‌ها:** مثلاً ترکیب -sn با -sV.

- **عدم توجه به خروجی:** نادیده گرفتن هشدارها و پیام‌های Nmap.

اسکن تمام پورت‌ها (-p-) بدون ضرورت: اتلاف زمان و ایجاد ترافیک غیرضروری.

## تفسیر غلط خروجی

- **اعتماد کامل به شناسایی OS:** نتایج -O همیشه قطعی نیستند.

تلقی open|filtered به معنای باز بودن پورت: این وضعیت عدم قطعیت را نشان می‌دهد.

- **نادیده گرفتن پورت‌های UDP:** بسیاری از سرویس‌های حیاتی (مانند DNS, DHCP, SNMP) روی UDP کار می‌کنند.

## مشکلات Performance

- **اسکن UDP بدون تنظیم timeout:** می‌تواند اسکن را به شدت کند کند.

استفاده از -T5 روی شبکه‌های شلوغ یا با تاخیر بالا: باعث از دست رفتن شدید بسته‌ها می‌شود.

اسکن هزاران میزبان بدون بهینه‌سازی: استفاده از --min-hostgroup و --min-rate برای مدیریت منابع ضروری است.
