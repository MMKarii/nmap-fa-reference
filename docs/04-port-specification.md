# ۴. Port Specification

این بخش تعیین می‌کند کدام پورت‌ها اسکن شوند.

## `-p (Port Specification)`

- **نحوه انتخاب پورت‌ها:** لیست، رنج یا ترکیبی از پورت‌ها را مشخص می‌کند.

- **پورت تکی:** -p 80

- **لیست:** -p 22,80,443

- **رنج:** -p 1-1000

- **ترکیب:** -p 22,80-100,443,8080

- **تمام پورت‌ها:** -p- (معادل -p 1-65535)

- **تاثیر روی سرعت:** اسکن تعداد پورت بیشتر، زمان بیشتری می‌برد.

**مثال:**

```bash
nmap -sS -p 22,80,443,8000-8100 192.168.1.1
```

## `-F (Fast Scan)`

- **نحوه انتخاب پورت‌ها:** فقط ۱۰۰ پورت رایج از فایل nmap-services را اسکن می‌کند.

- **تاثیر روی سرعت:** بسیار سریع.

- **تفاوت با Full Scan:** احتمال از دست دادن سرویس‌های روی پورت‌های غیرمعمول.

**مثال:**

```bash
nmap -sS -F 192.168.1.1
```

## `--top-ports <number>`

- **نحوه انتخاب پورت‌ها:** `<number>` پورت رایج را بر اساس فراوانی در فایل nmap-services اسکن می‌کند.

- **تاثیر روی سرعت:** سریع، اما بسته به تعداد پورت انتخابی.

**مثال:**

```bash
nmap -sS --top-ports 200 192.168.1.0/24
```

## `--port-ratio <ratio>`

- **نحوه انتخاب پورت‌ها:** تمام پورت‌هایی که نسبت فراوانی آن‌ها در فایل nmap-services بیشتر یا مساوی `<ratio>` باشد را اسکن می‌کند. `<ratio>` بین ۰ و ۱ است.

- **تاثیر روی سرعت:** بستگی به تعداد پورت‌های واجد شرط دارد.

**مثال:**

```bash
nmap -sS --port-ratio 0.001 192.168.1.1
```

(اسکن پورت‌هایی با فراوانی ۰.۱٪ یا بیشتر)

## `--exclude-ports <port list>`

- **نحوه انتخاب پورت‌ها:** پورت‌های مشخص شده را از اسکن حذف می‌کند. می‌تواند همراه با -p یا --top-ports استفاده شود.

- **تاثیر روی سرعت:** کاهش اندک زمان اسکن.

**مثال:**

```bash
nmap -p- --exclude-ports 1-1024,3389,8080 192.168.1.1
```
