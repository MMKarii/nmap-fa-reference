# ۷. OS Detection

## `-O (OS Detection)`

- **عملکرد:** Nmap با ارسال یک سری بسته‌های TCP، UDP و ICMP با ویژگی‌های خاص (مانند پنجره TCP، پرچم‌ها، گزینه‌ها) و تحلیل پاسخ‌های دقیق میزبان، اثرانگشت پشته TCP/IP آن را می‌سازد. این اثرانگعت با پایگاه‌داده nmap-os-db مقایسه می‌شود تا سیستم عامل احتمالی شناسایی شود.

- **TCP/IP Fingerprinting:** اساس کار این قابلیت است.

- **Active vs Passive Detection:** Nmap از روش فعال (Active) استفاده می‌کند. روش‌های Passive (مانند p0f) ترافیک موجود را تحلیل می‌کنند.

- **نیاز به Root:** دارد (برای ارسال بسته‌های خام و دریافت پاسخ‌ها).

- **محدودیت‌ها و دقت:** 

دقت بستگی به وجود اثرانگشت سیستم هدف در پایگاه‌داده دارد.

سیستم‌هایی با تنظیمات پشته TCP/IP تغییر یافته می‌توانند نتیجه را مخدوش کنند.

فایروال‌ها و دستگاه‌های شبکه میانی می‌توانند پاسخ‌ها را تغییر دهند.

معمولاً چند گزینه احتمالی با درصد احتمال ارائه می‌دهد.

**مثال:**

```bash
sudo nmap -O 10.10.10.10
```

## `--osscan-limit`

- **عملکرد:** OS Detection را فقط روی میزبان‌هایی اجرا می‌کند که حداقل یک پورت باز و یک پورت بسته دارند. این منطق شانس شناسایی دقیق را افزایش می‌دهد.

**مثال:**

```bash
sudo nmap -O --osscan-limit 192.168.1.0/24
```

## `--osscan-guess و --fuzzy`

- **عملکرد:** اگر Nmap نتواند با اطمینان بالا مطابقت دقیقی پیدا کند، با این سوئیچ‌ها بهترین حدس‌های خود را با درصد احتمال پایین‌تر نمایش می‌دهد.

**مثال:**

```bash
sudo nmap -O --osscan-guess 192.168.1.100
```
