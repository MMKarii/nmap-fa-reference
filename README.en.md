A structured Nmap reference for learning, quick lookup, and authorized security assessment.

## Documentation

- Persian: https://mmkarii.github.io/nmap-fa-reference/fa/
- English: https://mmkarii.github.io/nmap-fa-reference/en/

## Coverage

The project covers Nmap fundamentals, command syntax, host discovery, port specification, scan types, service and OS detection, NSE, firewall and IDS/IPS evasion concepts, timing, output formats, practical scenarios, result analysis, and common mistakes.

## Quick Start

```bash
nmap -sS -sV 192.168.1.1
```

Use every command only on systems and networks you own or are explicitly authorized to assess.

## Study paths

- Beginner: Fundamentals, Syntax, Host Discovery, Port Specification, Scan Types
- Intermediate: Service Detection, OS Detection, NSE, Output and Reporting
- Advanced: Timing, Filtering and Evasion, Practical Scenarios, Output Analysis
